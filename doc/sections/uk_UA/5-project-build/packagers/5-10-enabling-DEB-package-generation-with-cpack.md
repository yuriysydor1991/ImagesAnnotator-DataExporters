## Вмикання підтримки генерування DEB-пакетів з cpack

Для того щоб мати змогу згенерувати `deb`-пакет необіхдно сконфігурувати проект для підтримки команди `cpack` за допомогою змінної `ENABLE_DEB`:

```
# всередині кореневої директорії проекту 

mkdir -vp build && cd build && cmake ../ -DENABLE_DEB=ON
```

Наступним кроком буде збирання або компіляція усіх необхідних файлів які повинні входити у `deb`-пакет:

```
# всередині директорії побудови проекту-шаблону

cmake --build . --target all
```

На кінець, необіхдно виконати команду `cpack` всередині директорії побудови проекту-шаблону:

```
# всередині директорії побудови проекту-шаблону

cpack
```

Згенерований пакет повинен згенеруватись всередині кореня директорії побудови проекту. Наприклад, якщо ім'я проекту було не зміненим і його версія 0.8.0 тоді назва пакету може виглядати наступним чином: `CppAppTemplate-0.8.0-amd64-ubuntu-24.04.deb`.

Після версії назва пакету містить архітектуру центрального процесора цільової системи, ту ж, що і в полі `Architecture` пакету. Її містить кеш-змінна `TEMPLATE_PROJECT_DEB_PACKAGE_ARCHITECTURE` (типово: вивід команди `dpkg --print-architecture`, наприклад `amd64` чи `arm64`), тож її варто перевизначати при крос-компіляції проекту або пакуванні на хості без `dpkg`.

Якщо проект не крос-компілюється, за архітектурою слідують назва та версія цільової операційної системи, тобто самого хоста збирання: поля `ID` та `VERSION_ID` його файлу `/etc/os-release`, наприклад `ubuntu-24.04` чи `debian-13` (система з безперервним випуском, як-от Debian sid, називає лише свій `ID`). Їх містить кеш-змінна `TEMPLATE_PROJECT_PACKAGE_SYSTEM`, спільна для всіх пакувальників проекту. Крос-компільована збірка лишає її порожньою, тож назва її пакету містить лише архітектуру; задайте їй значення, щоб назвати цільову систему самостійно (наприклад `-DTEMPLATE_PROJECT_PACKAGE_SYSTEM=debian-13`), або порожній рядок, щоб не називати жодної.

Для того щоб переглянути або змінити параметри створення `deb`-пакетів необхідно відвідати файл `cmake/template-project-deb-enabler.cmake`.
