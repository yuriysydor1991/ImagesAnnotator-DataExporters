# Створення форку і заміна оригінального репозиторію

Щоб продовжити розробку бібліотеки самостійно, спершу створи її форк. Створення форку зазвичай виконується через Web-панель інтерфейсу Git-хостингу, на [сторінці проекту](https://github.com/yuriysydor1991/ImagesAnnotator-DataExporters).

Для того щоб натомість скопіювати увесь вміст проекту у новий чистий репозиторій (**чистий репозиторій без жодних файлів** на подобі `README.md`, `.gitignore`, `LICENSE` або будь-яких інших), склонуй поточний проект у свою локальну директорію і виконай заміну посилання оригінального репозиторію всередині кореневої директорії проекту:

```
# Заміни наступний URL на власний
git remote set-url origin https://github.com/yuriysydor1991/ImagesAnnotator-DataExporters.git
```

Заміни посилання `https://github.com/yuriysydor1991/ImagesAnnotator-DataExporters.git` на посилання свого новоствореного репозиторію.

Для того щоб перевірити, чи вдало замінився URL віддаленого репозиторію (куди будуть надсилатись усі зміни), необхідно виконати наступну команду:

```
git remote -v
```

Після виконання якої у терміналі повинен висвітлитись новий репозиторій.

Тепер можна надіслати свій репозиторій до нового розміщення, виконавши наступну команду:

```
git push
```

Щоб і надалі отримувати зміни з оригінального проекту після заміни, додай оригінальний репозиторій під окремим ім'ям віддаленого репозиторію:

```
git remote add upstream https://github.com/yuriysydor1991/ImagesAnnotator-DataExporters.git
git fetch upstream
```

Май на увазі, що ім'я проекту, ім'я створюваного бінарного файлу `libImagesAnnotatorDataExporters-0.11.so`, CMake-пакунок `ImagesAnnotatorDataExporters-0.11` і директорія встановлення заголовкових файлів `include/ImagesAnnotatorDataExporters-0.11/` - усі походять від імені CMake-проекту, тому перейменування форку означає перейменування і їх - переглянь підсекцію [Зміна імені проекту і виконуваного файлу](/doc/sections/uk_UA/4-project-structure/4-2-changing-the-project-and-executable-name.md).
